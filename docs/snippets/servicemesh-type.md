This Workshop Covers the support of:
* Kuma
* Linkerd with the Kgateway
* Istio
* Ambient Mesh
* Ambient Mesh with the Kgateway


The purpose is to define which service mesh you would like to try . 
This would be done by setting the right value to `SM_TYPE`.
The current value supported are:
- `none`: meaning that no service mesh would be deployed
- `linkerd`
- `istio`
- `ambient`
- `ambient-kgateway`
